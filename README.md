<h1>Portfolio</h1>

A simple, responsive personal portfolio website built with HTML, CSS, JavaScript, and Vite.


<h1>Features</h1>

Clean, responsive design

Sections for projects and contact info

Fast build & dev environment with Vite

<h1>Run Locally</h1>
git clone https://github.com/Fatemeh-Rasouli/Portfolio.git
cd Portfolio
npm install
npm run dev     # Start development server
npm run build   # Build for production
